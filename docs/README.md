# Anleitungen

Kurze Anleitungen für den Alltag mit Zwijg. Jede passt auf eine Seite.

1. [Erste Schritte](erste-schritte.md): starten, anmelden, Passwort, Benutzer anlegen
2. [Lokale KI einbinden](lokale-ki.md): Ollama installieren und mit Zwijg verbinden
3. [Cloud Anbieter einbinden](cloud-anbieter.md): Claude, ChatGPT und andere
4. [Im Chat arbeiten](im-chat-arbeiten.md): Vorschau, Vorlagen, Verstecken, Text schützen, Dokumente
5. [Texterkennung für Scans](texterkennung.md): Tesseract installieren, gescannte PDFs und Fotos lesen
6. [Diktieren](diktieren.md): Sprachmodell laden, im Chat sprechen statt tippen
7. [Schutz anpassen](schutz-anpassen.md): eigene Regeln, Namens- und Ortslisten
8. [Andere Programme anbinden](programme-anbinden.md): Zwijg als OpenAI kompatible Schnittstelle
9. [Betrieb in der Praxis](betrieb.md): Server, HTTPS, Sicherung, Updates
